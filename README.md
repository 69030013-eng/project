# 🍲 กินไรดี โรงอาหาร (KinRaiDee Smart Canteen & Calorie Manager)

เว็บแอปพลิเคชันอัจฉริยะสำหรับสุ่มและแนะนำอาหารในโรงอาหาร จัดสรรงบประมาณ คำนวณแคลอรี่ตามเกณฑ์ TDEE ป้องกันโรคอ้วน พร้อมระบบ AI สแกนวิเคราะห์ภาพถ่ายอาหารแบบครบวงจร

---

## ✨ ปัญหาที่แอปนี้ช่วยแก้ไข (Problem Statements)
1. **แก้ปัญหา "ไม่รู้จะกินอะไรดี" (Decisiveness & Variety)**: สุ่มเมนูอาหารในโรงอาหารด้วยวงล้อ Roulette พร้อมระบบ **Anti-Monotony Guard** ไม่สุ่มเมนูเดิมซ้ำกับที่เพิ่งกินไปใน 2 มื้อล่าสุด
2. **ป้องกันปัญหาโรคอ้วนและกินเกินแคลอรี่ (Calorie & Obesity Prevention)**: คำนวณ **BMR & TDEE** ตามหลักการแพทย์ (Mifflin-St Jeor) และมีโหมด **Strict Calorie Filter** กรองเมนูที่เกินโควต้าแคลอรี่คงเหลือของวันออกโดยอัตโนมัติ
3. **คุมงบประมาณค่าอาหาร (Budget Management)**: กำหนดงบต่อวัน (เช่น 150 บาท/วัน) หรือจำกัดงบเฉพาะมื้อ (เช่น ไม่เกิน 40-50 บาท) พร้อมแดชบอร์ดสรุปเงินคงเหลือแบบเรียลไทม์
4. **วิเคราะห์สารอาหารจากรูปถ่าย (AI Vision Scanner)**: ถ่ายรูปหรืออัปโหลดจานข้าว ให้ AI ระบุชื่อเมนู, กะขนาดจาน, คำนวณแคลอรี่, สัดส่วนสารอาหาร (โปรตีน/คาร์บ/ไขมัน/โซเดียม) และให้คำแนะนำจากนักกำหนดอาหาร

---

## 🚀 ฟีเจอร์หลัก (Core Features)

### 1. 🎯 วงล้อสุ่มอาหารอัจฉริยะ (Smart Food Roulette)
- วงล้อหมุนแบบฟิสิกส์แคนวาส (HTML5 Canvas) พร้อมเสียงติ๊กและเสียงฉลองเมื่อหยุด (Web Audio API สังเคราะห์เสียงในตัว ไม่ต้องโหลดไฟล์เสียง)
- ตัวกรองอัจฉริยะ:
  - เลือกร้านค้าเฉพาะ หรือสุ่มจากทุกร้านในโรงอาหาร
  - กรองตามงบประมาณ (ไม่จำกัด, ≤40฿, ≤50฿, หรืองบคงเหลือวันนี้)
  - กรองตามแคลอรี่คงเหลือวันนี้ (Strict TDEE Mode)
  - ตัวกรองป้องกันอาหารซ้ำ (Anti-Monotony)
- **ระบบปรับแต่งจานอาหาร (Custom Modifiers)**:
  - 🍚 เลือกปริมาณข้าว: ข้าวปกติ, ข้าวครึ่งจาน (-80 kcal), ไม่เอาข้าว (-160 kcal), ข้าวพิเศษ (+100 kcal / +5฿)
  - 🍳 ออปชันเสริม: เพิ่มไข่ต้ม (+75 kcal / +10฿), ไข่ดาว (+120 kcal / +10฿), ไม่ใส่กระเทียมเจียว (-50 kcal), ไม่เอาหนังไก่ (-70 kcal) ฯลฯ
  - คำนวณแคลอรี่และราคาสุทธิแบบเรียลไทม์ และกดบันทึกลงไดอารี่ได้ทันที

### 2. 📸 AI สแกนอาหาร (Gemini Vision Food Recognition)
- เชื่อมต่อ **Google Gemini 1.5 Flash / 2.0 Flash API**
- วิเคราะห์ชื่ออาหาร, กะปริมาณจาน, แคลอรี่, โปรตีน, คาร์โบไฮเดรต, ไขมัน, โซเดียม, ระดับเกรดสุขภาพ (A, B, C, D) และข้อควรระวัง
- **ระบบ Demo Mode อัจฉริยะ**: หากยังไม่ได้ใส่ API Key ระบบจะใช้ตัวอย่างฐานข้อมูลอาหารไทยมาตรฐาน ทำให้ทดสอบระบบได้ทันที 100%

### 3. ⚖️ เครื่องคิดคำนวณ TDEE & แผนโภชนาการ (TDEE Engine)
- คำนวณด้วยสูตร **Mifflin-St Jeor Equation** จาก เพศ, อายุ, น้ำหนัก, ส่วนสูง, และระดับกิจกรรม
- ประเมินดัชนีมวลกาย (**BMI**) ตามเกณฑ์มาตรฐานเอเชีย (สมส่วน, น้ำหนักเกิน, อ้วนระดับ 1-2)
- เลือกระดับเป้าหมาย: ลดไขมันเร่งด่วน (-500 kcal), ลดน้ำหนักยั่งยืน (-300 kcal), รักษาน้ำหนัก (คงที่), เพิ่มกล้ามเนื้อ (+350 kcal)
- คำนวณสัดส่วนสารอาหารหลัก (**Macronutrients**) โปรตีน/คาร์บ/ไขมัน และแนะนำการเกลี่ยแคลอรี่/งบตามมื้อ (เช้า 30%, เที่ยง 40%, เย็น 30%)

### 4. 🏪 จัดการร้านค้าและเมนูโรงอาหาร (Canteen & Stalls Manager) — ปรับปรุงใหม่ให้แก้ไขง่ายที่สุด
- **✏️ แก้ไขร้านค้าได้ใน 1 คลิก**:
  - กดปุ่ม **"✏️ แก้ไขร้าน"** หรือคลิกที่ชื่อ/ไอคอนร้าน เพื่อเปลี่ยนชื่อร้านทันที
  - มี **Visual Emoji Picker** คลิกเลือกไอคอนร้านได้ทันที (ไม่ต้องพิมพ์หรือเปิดคีย์บอร์ด)
  - มี **Color Theme Picker** คลิกเปลี่ยนสีธีมร้านได้ทันที
- **✏️ แก้ไขเมนูอาหารได้ทันที**:
  - มีปุ่ม **"✏️ แก้ไข"** ในทุกการ์ดเมนู หรือคลิกที่ตัวเมนูเพื่อแก้ไขราคา แคลอรี่ ชื่ออาหาร และหมวดหมู่ได้ทันที ไม่ต้องลบแล้วสร้างใหม่
  - มีปุ่มลัด **±5฿, ±10฿** สำหรับปรับราคาด่วน และปุ่ม **±50, ±100 kcal** สำหรับปรับแคลอรี่ด่วน (เหมาะมากสำหรับการใช้งานบนมือถือ)
- **📋 คัดลอกสร้างเมนูใหม่ทันที (Quick Duplicate)**:
  - เมนูไหนมีเวอร์ชันคล้ายกัน (เช่น กะเพราไก่ -> กะเพราไก่พิเศษ) กดปุ่ม **"📋 คัดลอก"** ระบบจะโคลนเมนูพร้อมปรับราคา/แคลอรี่ให้พร้อมแก้ไขต่อได้ใน 1 วินาที
- **🔍 ระบบค้นหาด่วน (Live Search)**:
  - ช่องพิมพ์ค้นหาชื่อร้านค้าหรือชื่อเมนูอาหารเพื่อกรองและเข้าไปแก้ไขได้อย่างรวดเร็ว
- **🏢 เปลี่ยนชื่อโรงอาหารได้ง่ายๆ**:
  - มีปุ่ม **"✏️ แก้ไขชื่อโรงอาหาร"** ให้ตั้งชื่อตามสถานที่จริงของผู้ใช้ (เช่น โรงอาหารกลาง, โรงอาหารตึก 1, โรงอาหารคณะวิศวะ ฯลฯ)
- มีชุดข้อมูลเริ่มต้นร้านค้าโรงอาหารไทยยอดนิยม 5 ร้าน พร้อมปุ่มสำรองข้อมูล (**Export JSON**) และนำเข้า (**Import JSON**)

### 5. 📖 ไดอารี่บันทึกมื้ออาหาร & ตั้งค่า (Diary & Settings)
- บันทึกการกินแยกตามมื้อ เช้า / กลางวัน / เย็น / ของว่าง
- สรุปแคลอรี่และเงินที่ใช้ไปวันนี้
- ช่องกรอก Google Gemini API Key พร้อมลิงก์กดรับฟรี

## 💻 วิธีการเปิดใช้งาน (How to Run)
1. **เปิดผ่านเบราว์เซอร์โดยตรง**: ดับเบิ้ลคลิกไฟล์ `start_app.bat` หรือเปิดไฟล์ `index.html` ด้วยเว็บเบราว์เซอร์ใดก็ได้ (Google Chrome, Microsoft Edge, Safari, Firefox, Opera)
2. **ใช้งานบนสมาร์ทโฟน**: สามารถแชร์เปิดบนเครือข่ายเดียวกัน หรือกด "Add to Home Screen" เพื่อติดตั้งเป็นแอป PWA บนหน้าจอมือถือได้ทันที
3. **ไม่ต้องติดตั้ง dependencies ใดๆ เพิ่มเติม** (No Node.js/Python required — แอปสร้างด้วย Vanilla JS + Tailwind CSS CDN ประมวลผลบน Client-Side 100%)
